# RobotControlSystem 文档索引

文档按照项目开发阶段归档。阶段目录表示文档产生时对应的主要目标，不表示其中方案已经全部实现；涉及当前行为时，应以代码和配置为准。

## 阶段1：基础功能与通信

目录：[阶段1-基础功能与通信](./阶段1-基础功能与通信/README.md)

主要包括系统初始架构、双向流式通信、任务调度、状态反馈、数据结构、日志系统和相机接入等基础能力。

## 阶段2：架构与容错增强

目录：[阶段2-架构与容错增强](./阶段2-架构与容错增强/README.md)

主要包括架构演进分析、组件故障隔离、健康状态监控、自动恢复及生产环境运维能力评估。

## 阶段3：生产稳定性升级

目录：[阶段3-生产稳定性升级](./阶段3-生产稳定性升级/README.md)

主要包括 gRPC 自动重连、离线消息、启动流程分离、数据库与日志优化、管理端适配和生产级审核。

## 阶段4：生产部署与运维

目录：[阶段4-生产部署与运维](./阶段4-生产部署与运维/README.md)

当前重点是将开发工程转化为可重复安装、开机自启、可监控、可升级、可回滚并具备基本防篡改能力的正式交付物。

## 维护规则

1. 新文档应放入对应阶段目录，不直接堆放在 `docs` 根目录。
2. 每个阶段的 `README.md` 负责说明阶段目标并维护文档索引。
3. 方案文档必须区分“计划”“已实施”和“已验证”，避免将设计稿误认为当前实现。
4. 文件移动或重命名后，应同步检查 Markdown 链接和代码中的文档路径。
5. 涉及账号、密码、Token、证书私钥的内容不得写入文档或示例配置。
