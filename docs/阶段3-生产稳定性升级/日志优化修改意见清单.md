# 日志优化修改意见清单

## 概述

对 Lumi 项目进行全面日志审计，共发现 **632 处日志调用**，其中存在以下两类问题：

| 问题类型 | 描述 | 数量 |
|---------|------|------|
| **问题 A** | 内容冗余或表意不清 | ~45 处 |
| **问题 B** | 日志等级使用不当 | ~65 处 |

---

## 日志等级使用规范（参考）

| 等级 | 使用场景 | 示例 |
|------|---------|------|
| **DEBUG** | 开发调试信息、内部流程细节、循环迭代 | 变量值、中间状态、方法调用 |
| **INFO** | 重要业务事件、系统状态变化 | 任务开始/完成、连接建立、模式切换 |
| **WARNING** | 可恢复的异常、重试操作、降级处理 | 超时重试、配置缺失但有默认值 |
| **ERROR** | 操作失败、需要关注的异常 | 任务失败、连接断开、硬件故障 |

## 附录：日志格式规范建议

### 统一格式模板

```python
# 任务/命令相关
logger.info(f"[命令 {cmd_id}] 任务 {task_id} 开始执行")
logger.info(f"[命令 {cmd_id}] 站点 {station_id} 执行完成")
logger.warning(f"[命令 {cmd_id}] 站点 {station_id} 重试 ({retry}/{max_retry})")
logger.error(f"[命令 {cmd_id}] 站点 {station_id} 执行失败: {error}")

# 硬件操作相关
logger.debug(f"[AGV] 发送命令: {cmd_type}")
logger.info(f"[AGV] 到达标记点 {marker_id}")
logger.error(f"[AGV] 移动失败: {error}")

# 连接/流相关
logger.info(f"[gRPC] {stream_name} 流已建立")
logger.warning(f"[gRPC] {stream_name} 流断开，准备重连")
logger.error(f"[gRPC] {stream_name} 流重连失败: {error}")
```

### 上下文信息检查清单

- [ ] 命令 ID（command_id）
- [ ] 任务 ID（task_id）
- [ ] 站点 ID（station_id）
- [ ] 设备 ID（device_id）
- [ ] 操作类型（operation_mode）
- [ ] 错误类型和详情（异常类名 + 消息）
- [ ] 重试次数（current/max）
