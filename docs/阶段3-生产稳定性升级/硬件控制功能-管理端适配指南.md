# 硬件使能/失能控制功能 - 管理端适配指南

## 一、功能概述

管理端可通过 gRPC `serverCommand` 双向流发送硬件启动/关闭命令，控制机器人端的三个硬件模块：
- **机器人**（AGV + 机械臂）
- **相机**
- **环境传感器**

## 二、通信协议

### 2.1 通信通道

| 方向 | RPC | 流类型 |
|------|-----|--------|
| 服务端 → 机器人 | `serverCommand` | 双向流 (ServerStreamMessage) |
| 机器人 → 服务端 | `serverCommand` | 双向流 (ClientStreamMessage) |

### 2.2 命令类型枚举

```protobuf
enum CmdType {
    // ... 其他命令 ...
    HARDWARE_START_CMD = 8;    // 硬件启动命令
    HARDWARE_SHUTDOWN_CMD = 9; // 硬件关闭命令
}
```

### 2.3 响应类型枚举

```protobuf
enum ClientMessageType {
    // ... 其他类型 ...
    HARDWARE_STATUS_RESPONSE = 6; // 硬件状态响应
}
```

## 三、消息定义

### 3.1 服务端下发命令 (ServerStreamMessage)

```protobuf
message ServerStreamMessage {
    int64 command_id = 1;              // 命令唯一ID
    int64 command_time = 2;            // 命令时间戳（毫秒）
    CmdType command_type = 3;          // HARDWARE_START_CMD 或 HARDWARE_SHUTDOWN_CMD
    int64 robot_id = 4;                // 机器人ID
    oneof data_json {
        // ... 其他命令 ...
        HardwareControlCommand hardware_control_cmd = 10;
    }
}

message HardwareControlCommand {
    bool robot = 1;       // 是否控制机器人（AGV+机械臂）
    bool camera = 2;      // 是否控制相机
    bool env_sensor = 3;  // 是否控制环境传感器
}
```

### 3.2 机器人响应消息 (ClientStreamMessage)

```protobuf
message ClientStreamMessage {
    int64 command_id = 1;              // 对应的命令ID
    int64 command_time = 2;            // 响应时间戳（毫秒）
    ClientMessageType command_type = 3; // HARDWARE_STATUS_RESPONSE
    int64 robot_id = 4;                // 机器人ID
    oneof data_json {
        // ... 其他响应 ...
        HardwareStatusResponse hardware_status = 10;
    }
}

message HardwareStatusResponse {
    bool robot_enabled = 1;      // 机器人当前启用状态
    bool camera_enabled = 2;     // 相机当前启用状态
    bool env_sensor_enabled = 3; // 环境传感器当前启用状态
    string message = 4;          // 响应消息（成功/失败原因）
}
```

## 五、Java 代码示例

### 5.1 发送硬件启动命令

```java
// 构建硬件控制命令
HardwareControlCommand hardwareCmd = HardwareControlCommand.newBuilder()
    .setRobot(true)        // 启动机器人
    .setCamera(true)       // 启动相机
    .setEnvSensor(true)    // 启动环境传感器
    .build();

// 构建服务端消息
ServerStreamMessage message = ServerStreamMessage.newBuilder()
    .setCommandId(generateCommandId())           // 生成唯一命令ID
    .setCommandTime(System.currentTimeMillis())  // 当前时间戳
    .setCommandType(CmdType.HARDWARE_START_CMD)  // 硬件启动命令
    .setRobotId(robotId)                         // 目标机器人ID
    .setHardwareControlCmd(hardwareCmd)          // 硬件控制参数
    .build();

// 通过 serverCommand 流发送
serverCommandStreamObserver.onNext(message);
```

### 5.2 发送硬件关闭命令

```java
// 构建硬件控制命令（仅关闭机器人，保持相机和传感器运行）
HardwareControlCommand hardwareCmd = HardwareControlCommand.newBuilder()
    .setRobot(true)         // 关闭机器人
    .setCamera(false)       // 不操作相机
    .setEnvSensor(false)    // 不操作环境传感器
    .build();

// 构建服务端消息
ServerStreamMessage message = ServerStreamMessage.newBuilder()
    .setCommandId(generateCommandId())
    .setCommandTime(System.currentTimeMillis())
    .setCommandType(CmdType.HARDWARE_SHUTDOWN_CMD)  // 硬件关闭命令
    .setRobotId(robotId)
    .setHardwareControlCmd(hardwareCmd)
    .build();

// 发送
serverCommandStreamObserver.onNext(message);
```

### 5.3 处理硬件状态响应

```java
@Override
public void onNext(ClientStreamMessage response) {
    if (response.getCommandType() == ClientMessageType.HARDWARE_STATUS_RESPONSE) {
        HardwareStatusResponse status = response.getHardwareStatus();

        // 更新UI状态
        updateRobotButton(status.getRobotEnabled());
        updateCameraButton(status.getCameraEnabled());
        updateEnvSensorButton(status.getEnvSensorEnabled());

        // 显示消息
        showMessage(status.getMessage());

        log.info("硬件状态更新 - 机器人:{}, 相机:{}, 传感器:{}, 消息:{}",
            status.getRobotEnabled(),
            status.getCameraEnabled(),
            status.getEnvSensorEnabled(),
            status.getMessage());
    }
}
```

## 七、注意事项

1. **命令字段含义**：`HardwareControlCommand` 中的布尔值表示"是否操作该模块"，而非目标状态
   - `HARDWARE_START_CMD` + `robot=true` → 启动机器人
   - `HARDWARE_SHUTDOWN_CMD` + `robot=true` → 关闭机器人
   - `robot=false` → 不操作机器人（保持当前状态）

2. **响应字段含义**：`HardwareStatusResponse` 返回的是操作后的**实际状态**
   - `robot_enabled=true` → 机器人当前已启动
   - `robot_enabled=false` → 机器人当前已关闭

3. **命令ID**：建议使用递增ID或UUID，用于追踪命令执行结果

4. **超时处理**：建议设置命令超时（如10秒），超时后提示用户操作失败

5. **状态同步**：机器人端启动时会根据配置自动启动硬件，管理端应在连接建立后查询当前状态
