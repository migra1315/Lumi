## 1. 系统概述

### 1.1 项目背景

Lumi 是一个基于 Python 的智能巡检机器人控制系统，负责协调：
- **AGV（Automated Guided Vehicle）**: 自主导航小车
- **机械臂（Robotic Arm）**: JAKA 六轴机械臂
- **外部轴（External Axis）**: 四轴扩展装置
- **环境传感器**: 温湿度、PM2.5、噪音等传感器

### 1.2 系统角色

本文档面向**后台服务器开发人员**，后台服务器的职责包括：
- 向机器人下发巡检任务
- 接收机器人状态和巡检数据
- 监控机器人运行状态
- 控制机器人工作模式

### 1.3 通信方式

系统采用 **gRPC 双向流式通信**，确保：
- ✅ 实时数据推送
- ✅ 低延迟命令下发
- ✅ 持久化连接
- ✅ 双向数据流

### 2.2 数据流向

#### 2.2.1 命令下发流程（后台 → 机器人）

```
后台服务器
    ↓ [ServerStreamMessage via serverCommand流]
RobotControlSystem._handle_serverCommand()
    ↓ [convert_server_message_to_command_envelope()]
TaskManager.receive_command(CommandEnvelope)
    ↓ [create_unified_command() - 统一封装]
TaskScheduler.add_command(UnifiedCommand)
    ↓ [优先级队列 PriorityQueue]
TaskScheduler._execute_command()
    ↓ [根据cmd_type路由到对应executor]
    ├─ _execute_task_command()
    ├─ _execute_mode_command()
    ├─ _execute_joy_command()
    ├─ _execute_charge_command()
    └─ ...
```

#### 2.2.2 状态上报流程（机器人 → 后台）

```
RobotController 状态变化
    ↓ [TaskManager回调机制]
TaskManager 触发系统回调
    ↓ [on_data_ready / on_command_status_change / ...]
RobotControlSystem 回调处理函数
    ↓ [构建MessageEnvelope / ClientStreamMessage]
    ├─ _report_robot_status() → clientUpload流
    ├─ _report_environment_data() → clientUpload流
    ├─ _report_device_data() → clientUpload流
    ├─ _report_arrive_service_point() → clientUpload流
    
    ---> serverCommand流
    ├─ _send_command_status_update() → serverCommand流 (反向)
    ├─ _send_task_progress_update() → serverCommand流 (反向)
    └─ _send_operation_result() → serverCommand流 (反向)
```

## 3. gRPC 通信机制

### 3.1 gRPC 服务定义

**文件位置**: `gRPC/proto/RobotService.proto`

```protobuf
service RobotService {
    // 双向流式通信: 上传机器人状态、设备数据、环境数据、到达服务点位数据
    rpc clientUpload(stream RobotUploadRequest) returns (stream RobotUploadResponse);

    // 双向流式通信: 推送任务分配、服务指令
    rpc serverCommand(stream ClientStreamMessage) returns (stream ServerStreamMessage);
}
```

### 3.2 两条独立双向流

系统使用 **两条独立的双向流**，职责分离：

#### 3.2.1 clientUpload 流

**用途**: 机器人 → 后台的持续数据上传

**机器人发送** (RobotUploadRequest):
- 机器人状态 (ROBOT_STATUS)
- 设备采集数据 (DEVICE_DATA) - 如图像
- 环境数据 (ENVIRONMENT_DATA) - 温湿度、PM2.5等
- 到达服务点通知 (ARRIVE_SERVER_POINT)

**后台响应** (RobotUploadResponse):
- 简单确认响应 (code, info)

**上报策略**:
- 机器人状态: 每 **10秒** 定时上报
- 环境数据: 每 **30秒** 定时上报
- 设备数据: **事件触发** (站点完成后上报)
- 到达服务点: **事件触发** (AGV到达站点时上报)

#### 3.2.2 serverCommand 流

**用途**: 双向命令/状态通信

**后台发送** (ServerStreamMessage):
- 任务下发 (TASK_CMD)
- 模式切换 (ROBOT_MODE_CMD)
- 手动控制 (JOY_CONTROL_CMD)
- 充电命令 (CHARGE_CMD)
- 设置标记点 (SET_MARKER_CMD)
- 位置调整 (POSITION_ADJUST_CMD)

**机器人发送** (ClientStreamMessage) - **新增反向通信**:

- 心跳 (HEARTBEAT)
- 命令状态更新 (COMMAND_STATUS_UPDATE)
- 任务进度更新 (TASK_PROGRESS_UPDATE)
- 操作结果反馈 (OPERATION_RESULT)

> **重要**: serverCommand 流支持 **双向通信**，机器人可以通过此流主动向后台发送命令执行状态。

### 3.3 流管理器 (StreamManager)

**实现类**:
- `ClientUploadStreamManager`: 管理 clientUpload 流
- `ServerCommandStreamManager`: 管理 serverCommand 流

**核心功能**:
- 持久化连接管理
- 消息队列缓冲
- 自动重连机制
- 异常处理与恢复
- 线程安全操作

**使用示例**:
```python
# 初始化流管理器
client_upload_manager = ClientUploadStreamManager(stub, robot_id)
server_command_manager = ServerCommandStreamManager(stub, robot_id)

# 启动双向流
client_upload_manager.start_stream()
server_command_manager.start_stream()

# 设置响应处理器
client_upload_manager.response_handler = handle_upload_response
server_command_manager.response_handler = handle_command

# 发送消息
client_upload_manager.send_message(robot_upload_request)
server_command_manager.send_message(client_stream_message)
```

```protobuf
    int32 sort = 2;                       // 站点执行顺序
    string name = 3;                      // 站点名称
    string agv_marker = 4;                // AGV导航点标识
    repeated double robot_pos = 5;        // 机械臂归位位置 [J1-J6]
    repeated double ext_pos = 6;          // 外部轴归位位置 [J1-J4]

    OperationMode operation_mode = 1;     // 操作模式
```

**站点执行逻辑**:
1. AGV 移动到 `agv_marker` 位置
2. 机械臂移动到 `robot_pos` 归位位置
3. 外部轴移动到 `ext_pos` 归位位置
4. 执行 `operation_config` 指定的操作
5. 如果失败，自动重试（最多 `max_retries` 次，默认3次）
6. 重试失败后，继续执行下一个站点（不阻塞）

```protobuf
    string message = 12;                    // 进度消息

}
```

**触发时机**:
- 任务开始执行
- 每个站点开始/完成时
- 站点执行阶段变化时（移动AGV、移动机械臂、执行操作等）

**current_station_phase 可能的值**:
- `"AGV_MOVING"` - AGV移动中
- `"ARM_MOVING"` - 机械臂移动中
- `"EXT_MOVING"` - 外部轴移动中

#### 6.2.1 gRPC 服务实现

```java
import io.grpc.stub.StreamObserver;
import org.springblade.robot.grpc.RobotServiceGrpc;
import org.springblade.robot.grpc.RobotServiceProto.*;

public class RobotServiceImpl extends RobotServiceGrpc.RobotServiceImplBase {

    @Override
    public StreamObserver<RobotUploadRequest> clientUpload(
            StreamObserver<RobotUploadResponse> responseObserver) {

        return new StreamObserver<RobotUploadRequest>() {
            @Override
            public void onNext(RobotUploadRequest request) {
                // 处理机器人上传的数据
                handleUploadRequest(request, responseObserver);
            }

            @Override
            public void onError(Throwable t) {
                log.error("clientUpload stream error", t);
            }

            @Override
            public void onCompleted() {
                responseObserver.onCompleted();
            }
        };
    }

    @Override
    public StreamObserver<ClientStreamMessage> serverCommand(
            StreamObserver<ServerStreamMessage> responseObserver) {

        // 保存流引用，用于后续发送命令
        robotCommandStreams.put(robotId, responseObserver);

        return new StreamObserver<ClientStreamMessage>() {
            @Override
            public void onNext(ClientStreamMessage message) {
                // 处理机器人发送的反馈消息
                handleClientMessage(message);
            }

            @Override
            public void onError(Throwable t) {
                log.error("serverCommand stream error", t);
                robotCommandStreams.remove(robotId);
            }

            @Override
            public void onCompleted() {
                robotCommandStreams.remove(robotId);
            }
        };
    }

    private void handleUploadRequest(RobotUploadRequest request,
                                     StreamObserver<RobotUploadResponse> responseObserver) {
        long robotId = request.getRobotId();
        MsgType msgType = request.getMsgType();

        switch (msgType) {
            case ROBOT_STATUS:
                // 处理机器人状态
                handleRobotStatus(request.getRobotStatus(), robotId);
                break;

            case DEVICE_DATA:
                // 处理设备数据（图像）
                handleDeviceData(request.getDeviceData(), robotId);
                break;

            case ENVIRONMENT_DATA:
                // 处理环境数据
                handleEnvironmentData(request.getEnvironmentData(), robotId);
                break;

            case ARRIVE_SERVER_POINT:
                // 处理到达服务点通知
                handleArriveServicePoint(request.getArriveServicePoint(), robotId);
                break;
        }

        // 发送响应
        RobotUploadResponse response = RobotUploadResponse.newBuilder()
            .setMsgId(request.getMsgId())
            .setMsgTime(System.currentTimeMillis())
            .setMsgType(msgType)
            .setRobotId(robotId)
            .setDataJson(ServerResponse.newBuilder()
                .setCode("200")
                .setInfo("success")
                .build())
            .build();

        responseObserver.onNext(response);
    }

    private void handleClientMessage(ClientStreamMessage message) {
        ClientMessageType messageType = message.getCommandType();

        switch (messageType) {
            case COMMAND_STATUS_UPDATE:
                // 处理命令状态更新
                handleCommandStatusUpdate(message.getCommandStatus());
                break;

            case TASK_PROGRESS_UPDATE:
                // 处理任务进度更新
                handleTaskProgressUpdate(message.getTaskProgress());
                break;

            case OPERATION_RESULT:
                // 处理操作结果
                handleOperationResult(message.getOperationResult());
                break;

            case HEARTBEAT:
                // 处理心跳
                updateRobotHeartbeat(message.getRobotId());
                break;
        }
    }
}
```

```java
public class RobotCommandService {

    private final Map<Long, StreamObserver<ServerStreamMessage>> robotCommandStreams;

    public void sendTaskCommand(long robotId, TaskCommand taskCommand) {
        StreamObserver<ServerStreamMessage> stream = robotCommandStreams.get(robotId);

        if (stream == null) {
            throw new RuntimeException("Robot not connected: " + robotId);
        }

        // 构建站点配置
        List<Station> stations = new ArrayList<>();
        for (StationDTO stationDTO : taskCommand.getStations()) {
            OperationConfig operationConfig = OperationConfig.newBuilder()
                .setOperationMode(OperationMode.valueOf(stationDTO.getOperationMode()))
                .setDoorIp(stationDTO.getDoorIp())
                .setDeviceId(stationDTO.getDeviceId())
                .build();

            StationConfig stationConfig = StationConfig.newBuilder()
                .setStationId(stationDTO.getStationId())
                .setSort(stationDTO.getSort())
                .setName(stationDTO.getName())
                .setAgvMarker(stationDTO.getAgvMarker())
                .addAllRobotPos(stationDTO.getRobotPos())
                .addAllExtPos(stationDTO.getExtPos())
                .setOperationConfig(operationConfig)
                .build();

            Station station = Station.newBuilder()
                .setStationConfig(stationConfig)
                .setStatus(StationTaskStatus.STATION_TASK_STATUS_PENDING)
                .setMaxRetries(3)
                .build();

            stations.add(station);
        }

        // 构建任务
        Task task = Task.newBuilder()
            .setTaskId(taskCommand.getTaskId())
            .setTaskName(taskCommand.getTaskName())
            .addAllStationList(stations)
            .setStatus(TaskStatus.TASK_STATUS_PENDING)
            .setRobotMode(RobotMode.INSPECTION)
            .setGenerateTime(System.currentTimeMillis())
            .setCreatedAt(System.currentTimeMillis())
            .build();

        // 构建服务端命令消息
        ServerStreamMessage message = ServerStreamMessage.newBuilder()
            .setCommandId(generateCommandId())
            .setCommandTime(System.currentTimeMillis())
            .setCommandType(CmdType.TASK_CMD)
            .setRobotId(robotId)
            .setTaskCmd(task)
            .build();

        // 发送命令
        stream.onNext(message);

        log.info("Task command sent to robot {}: {}", robotId, taskCommand.getTaskId());
    }

    public void sendModeCommand(long robotId, RobotMode mode) {
        StreamObserver<ServerStreamMessage> stream = robotCommandStreams.get(robotId);

        if (stream == null) {
            throw new RuntimeException("Robot not connected: " + robotId);
        }

        RobotModeCommand modeCommand = RobotModeCommand.newBuilder()
            .setRobotMode(mode)
            .build();

        ServerStreamMessage message = ServerStreamMessage.newBuilder()
            .setCommandId(generateCommandId())
            .setCommandTime(System.currentTimeMillis())
            .setCommandType(CmdType.ROBOT_MODE_CMD)
            .setRobotId(robotId)
            .setRobotModeCommand(modeCommand)
            .build();

        stream.onNext(message);

        log.info("Mode command sent to robot {}: {}", robotId, mode);
    }
}
```

#### 6.2.3 处理机器人状态

```java
public class RobotStatusHandler {

    @Autowired
    private RobotStatusRepository robotStatusRepository;

    public void handleRobotStatus(RobotStatusUpload status, long robotId) {
        // 提取电池信息
        BatteryInfo batteryInfo = status.getBatteryInfo();
        double powerPercent = batteryInfo.getPowerPercent();
        String chargeStatus = batteryInfo.getChargeStatus();

        // 提取系统状态
        SystemStatus systemStatus = status.getSystemStatus();
        MoveStatus moveStatus = systemStatus.getMoveStatus();
        boolean isConnected = systemStatus.getIsConnected();
        boolean estopStatus = systemStatus.getEstopStatus();

        // 保存到数据库
        RobotStatusEntity entity = new RobotStatusEntity();
        entity.setRobotId(robotId);
        entity.setPowerPercent(powerPercent);
        entity.setChargeStatus(chargeStatus);
        entity.setMoveStatus(moveStatus.name());
        entity.setIsConnected(isConnected);
        entity.setEstopStatus(estopStatus);
        entity.setUpdateTime(new Date());

        robotStatusRepository.save(entity);

        // 电量低告警
        if (powerPercent < 20.0 && !"charging".equals(chargeStatus)) {
            sendLowBatteryAlert(robotId, powerPercent);
        }

        // 急停告警
        if (estopStatus) {
            sendEstopAlert(robotId);
        }

        log.info("Robot {} status updated: battery={}%, move={}, estop={}",
                 robotId, powerPercent, moveStatus, estopStatus);
    }

    public void handleEnvironmentData(EnvironmentDataUpload data, long robotId) {
        EnvironmentInfo envInfo = data.getSensorData();

        // 保存环境数据
        EnvironmentDataEntity entity = new EnvironmentDataEntity();
        entity.setRobotId(robotId);
        entity.setTemperature(envInfo.getTemperature());
        entity.setHumidity(envInfo.getHumidity());
        entity.setPm25(envInfo.getPm25());
        entity.setPm10(envInfo.getPm10());
        entity.setNoise(envInfo.getNoise());
        entity.setCollectTime(new Date());

        environmentDataRepository.save(entity);

        // 环境异常告警
        if (envInfo.getTemperature() > 40.0 || envInfo.getTemperature() < 0.0) {
            sendTemperatureAlert(robotId, envInfo.getTemperature());
        }

        if (envInfo.getPm25() > 75.0) {
            sendPM25Alert(robotId, envInfo.getPm25());
```

### 6.3 连接管理建议

#### 6.3.1 多机器人连接管理

```java
public class RobotConnectionManager {

    // 管理所有机器人的 serverCommand 流
    private final Map<Long, StreamObserver<ServerStreamMessage>> commandStreams =
        new ConcurrentHashMap<>();

    // 管理机器人连接状态
    private final Map<Long, RobotConnectionInfo> connectionInfoMap =
        new ConcurrentHashMap<>();

    public void registerRobot(long robotId, StreamObserver<ServerStreamMessage> stream) {
        commandStreams.put(robotId, stream);

        RobotConnectionInfo info = new RobotConnectionInfo();
        info.setRobotId(robotId);
        info.setConnectTime(new Date());
        info.setLastHeartbeat(new Date());
        info.setOnline(true);

        connectionInfoMap.put(robotId, info);

        log.info("Robot {} connected", robotId);

        // 发送连接成功通知
        sendConnectionNotification(robotId, true);
    }

    public void unregisterRobot(long robotId) {
        commandStreams.remove(robotId);

        RobotConnectionInfo info = connectionInfoMap.get(robotId);
        if (info != null) {
            info.setOnline(false);
            info.setDisconnectTime(new Date());
        }

        log.warn("Robot {} disconnected", robotId);

        // 发送断开连接告警
        sendConnectionNotification(robotId, false);
    }

    public void updateHeartbeat(long robotId) {
        RobotConnectionInfo info = connectionInfoMap.get(robotId);
        if (info != null) {
            info.setLastHeartbeat(new Date());
        }
    }

    public boolean isRobotOnline(long robotId) {
        RobotConnectionInfo info = connectionInfoMap.get(robotId);
        return info != null && info.isOnline();
    }

    public StreamObserver<ServerStreamMessage> getCommandStream(long robotId) {
        return commandStreams.get(robotId);
    }

    // 定时检查心跳超时
    @Scheduled(fixedRate = 30000) // 每30秒检查一次
    public void checkHeartbeatTimeout() {
        long now = System.currentTimeMillis();
        long timeout = 60000; // 60秒超时

        for (Map.Entry<Long, RobotConnectionInfo> entry : connectionInfoMap.entrySet()) {
            RobotConnectionInfo info = entry.getValue();
            if (info.isOnline()) {
                long lastHeartbeat = info.getLastHeartbeat().getTime();
                if (now - lastHeartbeat > timeout) {
                    long robotId = entry.getKey();
                    log.warn("Robot {} heartbeat timeout", robotId);
                    unregisterRobot(robotId);
                }
            }
        }
    }
}
```

## 7. 错误处理

### 7.1 常见错误场景

#### 7.1.1 连接错误

**错误**: gRPC 连接失败

**原因**:
- 后台服务器未启动
- 网络不通
- 端口被占用
- 防火墙阻止

**处理**:
- 机器人端会自动重试连接
- 检查网络配置
- 确认端口开放

#### 7.1.2 消息格式错误

**错误**: proto 消息解析失败

**原因**:
- proto 文件版本不一致
- 必填字段缺失
- 数据类型不匹配

**处理**:
- 确保双方使用相同版本的 proto 文件
- 检查消息构建代码
- 使用 proto 验证工具

#### 7.1.3 任务执行错误

**错误**: 任务执行失败

**原因**:
- AGV 无法到达目标点
- 机械臂关节位置超限
- 操作执行失败（门禁故障、拍照失败等）

**处理**:
- 机器人会自动重试（最多3次）
- 失败后上报详细错误信息
- 后台根据错误类型决定是否重新下发任务

### 7.2 错误码定义

**建议后台定义统一的错误码体系**:

| 错误码 | 错误类型 | 描述 |
|--------|---------|------|
| 1000 | CONNECTION_ERROR | 连接错误 |
| 1001 | HEARTBEAT_TIMEOUT | 心跳超时 |
| 2000 | INVALID_COMMAND | 无效命令 |
| 2001 | COMMAND_TIMEOUT | 命令超时 |
| 2002 | COMMAND_REJECTED | 命令被拒绝 |
| 3000 | TASK_FAILED | 任务失败 |
| 3001 | STATION_FAILED | 站点失败 |
| 3002 | OPERATION_FAILED | 操作失败 |
| 4000 | AGV_ERROR | AGV 错误 |
| 4001 | ARM_ERROR | 机械臂错误 |
| 4002 | SENSOR_ERROR | 传感器错误 |
| 5000 | LOW_BATTERY | 电量低 |
| 5001 | ESTOP_ACTIVATED | 急停激活 |
