# Domain Rules

> Project-specific document.

This file should contain business/domain invariants that coding agents must not rediscover or reinterpret on every task.

Recommended contents:

- domain terminology;
- state transitions;
- invariants;
- permission rules;
- validation rules;
- lifecycle constraints;
- error semantics;
- edge cases with business meaning;
- externally mandated constraints.

Only record rules supported by the repository, authoritative documentation, or explicit user requirements.
